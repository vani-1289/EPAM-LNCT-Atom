## 🎯 Purpose of This Repository

The primary objective of this repository is to maintain a structured record of the work performed by each student during the EPAM CoE journey.

It provides a shared space to document individual progress, demonstrate practical skills, track assigned responsibilities, and showcase project outcomes.

Through this repository, we aim to:

* Document individual project implementations and practical assignments.
* Maintain records of tasks performed by each student.
* Showcase code, experiments, research, and technical deliverables.
* Track individual contributions and learning progress.
* Encourage accountability, collaboration, and consistent documentation.
* Build a portfolio of practical work completed during the program.
